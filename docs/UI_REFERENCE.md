# MediaHub Live · 影院界面参考（2026-10-20）

这次重构以用户提供的 HD.Rip 桌面截图为布局基准。不复制其注册商标、节目内容、频道私有接口、图标资源或专有素材。

## 桌面布局

- 约 81px 的深色顶部栏，保留 MediaHub Live Logo、实际频道数量、播放器技术说明、GitHub 清单、源管理与导入。
- 频道栏约占页面宽度的 26%，左栏独立滚动，左栏顶部只有搜索，下面独立滚动显示频道编号、频道台标、名称及可用线路标记；取消分组、来源、收藏/最近标签栏。
- 右侧主要是大屏黑色视频区，约 2.32:1 的显示容器与 object-fit:contain 的视频内容，避免拉伸原始画面。
- 视频下方是紧邻的信息面板，包含当前频道、收藏、换台、播放、备用线路、画中画、全屏与真实状态。
- 状态来自浏览器 Video API 的 videoWidth/videoHeight/buffered。使用 hls.js 时才读取 manifest 中的 codec 和标称 bitrate；不可读取或未选择频道时显示 —。
- GitHub 频道库、M3U 导入、源管理、收藏和 IndexedDB 历史仍然可用。

## 移动端

- 频道面板排在顶部，播放器排在下方，频道列表继续可独立滚动。
- 视频容器切换为 16:9，浏览器默认视频 controls 保留原生播放能力。
- 收藏、源管理、GitHub 频道库、换台、线路选择仍可使用。

## 不伪造尚未实现的功能

P2P、弹幕和 XMLTV 节目表尚未接入。UI 不宣称它们已启用，也不虚构频道数、H.264/H.265 编码、实时吞吐量。标称码率不等于实际实时网速。

## 变更边界

不更改 M3U 解析、持久化数据结构、已导入频道或公开源 URL；不新增视频代理、D1、R2、Worker、Cloudflare Access。GitHub Actions 运行原有测试和新增布局结构检查。最终真实浏览器与直播端到端验收由用户在生产环境完成。

## 参考频道目录

默认载入原站公开 JSON-LD 的 184 条频道名称及编号，包含无播放源的付费台。免费候选源显示 HLS 标识，缺少 URL 则显示“待绑定”并可添加私人播放地址。导入私人 M3U 后可按 TVG ID 和唯一频道名匹配；同名不同编号时不做不确定自动关联。

## 缓存/资源一致性

`index.html` 引用 `/src/styles.css?v=20261020-theater8` 和 `/src/main.js?v=20261020-theater8`；`public/_headers` 指定 /src/* 重新验证缓存，避免 CSS/JS 版本错配。生产验收时需检查 Safari 新标签页、强制刷新后的播放器下方卡片是否保持排版。
