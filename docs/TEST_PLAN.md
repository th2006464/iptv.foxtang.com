# Fox IPTV — 测试计划

## 自动测试

    npm ci
    npm run check
    git diff --check

检查 M3U 中文、属性与逗号、备用线路合并、错误源过滤、HLS 媒体清单拒绝、稳定频道 ID、收藏保留及来源级联删除。Node 原生测试不依赖额外测试框架。

## 上线后由使用者完成的浏览器手工验收

| 场景 | 预期 |
|---|---|
| 首次打开 | 无真实频道，显示导入引导 |
| 文件导入和拖拽 | 显示预览；确认后入库 |
| 粘贴 M3U | 中文、逗号、多个分组正确 |
| HTTPS 订阅 | CORS 允许可读取，不允许时显示提示 |
| 错误协议 | 拒绝 javascript/file/rtsp 等 URL |
| #EXT-X HLS 文件 | 提示应当使用单个直播 URL |
| 收藏后刷新 | 仍保留 |
| 远程订阅更新 | 同稳定频道 ID 保存收藏 |
| 删除来源 | 仅删除本来源相关频道 |
| 播放与换台 | 原生/HLS 可用时播放，切换时旧音频停止 |
| 断流与 HTTP 地址 | 显示错误，不泄漏完整私人 URL |
| 备份与恢复 | 完整还原来源、频道和收藏 |
| 375px 手机 | 播放器在频道列表上方，无横向溢出 |
| 公开访问 | 无需 Cloudflare Access 或登录即可打开网站 |
| Pages 默认域名 | 可以直接访问，这是首版的预期状态 |

第一版先公开部署，再由使用者进行浏览器 UI 和直播播放验收。GitHub 合并前自动测试必须通过；尚未执行的手工验收不能写成通过。
