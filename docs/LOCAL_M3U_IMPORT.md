# 本机导入抓取的 M3U（HD.Rip 频道编号）

**仅限你有权访问的播放源。** 这份文档不包含、上传或公开复制 HD.Rip 的签名链接。不会自动请求、续签、伪造令牌，不会绕过 DRM、来源限制或地区授权。

## 导入方式

1. 打开部署后的 `https://iptv.foxtang.com/`。
2. 点击右上角齿轮「源管理」→「添加频道源」→「本地文件」。
3. 选择电脑/手机上的 `.m3u` 或 `.txt` 文件（用户已抓到的清单属于 `#EXTM3U`）。
4. 预览会计算 **184 个 tvg-id 数字匹配结果**，检查签名过期时间；确认后才写入当前浏览器 IndexedDB。
5. 返回原有频道目录，点击频道，在「播放线路」或「⇄ 换线路」中切换。新导入源优先于以前失效的公开源。

在本机导入的完整 184 台数字编号清单存放为固定私有来源 `personal-hd-reference-snapshot-v1`，**再次导入会替换上次这份来源**，不会新添 184 行重复频道；原有私人源和收藏不删除。页面一台电视台只显示一个条目。

## 签名地址过期

抓取的播放地址包含查询参数 `e`（Unix 秒时间戳）、`s` 等临时凭据。对 hd.rip 域名且有 `s` 的地址，播放器可以识别 `e`，并在预览显示最早到期时间；到期的地址不会继续尝试，已有其他合法公开源仍可使用。

用户提供的样本中的 184 个地址，`e` 表示 **2026-10-21 UTC** 当天到期。这不意味着链接在到期前一定可用，也不意味着之后一定不可用；它们可能还依赖 Cookie、来源站点、地区或其他播放环境约束。

**无法通过 F12 抓包让这些链接自动永久有效。** 即使视频请求可见，是否可以在其他网页独立播放取决于合法权限、浏览器限制和原服务的访问控制。

## 安全范围

- 原始签名 M3U **不进入公共 GitHub、Cloudflare Worker/D1/R2、构建产物或 GitHub Actions 日志**。
- 导入数据和链接凭据在浏览器 IndexedDB 中保存（本地缓存）；网站不会代替用户上传数据或同步到其他手机/电脑。
- 页面的「导出私人备份」包含这些私人 URL，因此请勿公开分享备份文件。
- 若第三方源拒绝跨域请求、要求 DRM/身份验证、发生 403/404/视频编码不兼容，本站不会尝试绕过；可以试用拥有授权的原生播放服务。
- 自动匹配优先识别数字 `tvg-id`，解决「中视」之类重名频道不能准确关联的问题；对于其他公开源，继续通过名称和常见 TVG ID 别名匹配。

## 排查播放质量

优先测试某个免费频道（例如阿里郎或 France 24）和其公开 CDN 线路，区分浏览器兼容性问题与第三方签名问题。如果播放成功，`hls.js` 可能提供 master manifest 声明的码率和编解码器、浏览器 Video API 可能提供分辨率。**这些数据不是用户实时网速，也不能靠切换 URL 提升源自身提供的最高画质。**
