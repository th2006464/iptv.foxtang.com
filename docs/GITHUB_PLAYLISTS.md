# GitHub 公开频道库

MediaHub Live 内置一个可选择、可预览的公开 M3U 清单库，但**不会默认下载或保存所有第三方公开源**。

## 数据地址

官方来源：https://github.com/iptv-org/iptv

官方清单格式：https://github.com/iptv-org/iptv/blob/master/PLAYLISTS.md

频道元数据 API：https://github.com/iptv-org/api

本项目提供 iptv-org GitHub Pages 上按地区或分类的 M3U 地址快捷入口，共 13 类。用户打开“GitHub 频道库”，选择地区或分类，网页直接从 https://iptv-org.github.io/iptv/ 获取最新 M3U，先预览数量，再确认导入浏览器 IndexedDB。订阅来源可在“源管理”中单独更新、禁用或者删除，私人 M3U 不受影响。

分类：新闻、财经、纪录片、科技科学。

地区：美国、中国大陆、中国香港、中国台湾、日本、韩国、新加坡、法国、德国。

这些地址来自公共 GitHub 项目，而不是已确认的 HD.Rip 私有播放接口。目录中的公开链接不意味着已取得再分发授权，也无法保证源在所有国家、设备上可用。导入后频道直接由浏览器访问源站，本站不代理视频、转码、处理 DRM 或绕过地区限制。任何需要特殊 Referrer、Cookies、Authorization、DRM 或付费订阅的源，可能在浏览器中直接失败。

## 为什么不自动导入所有频道

完整索引量级较大，包含重复流、失效流、地区限制和兼容性问题。默认采用 184 个 HD.Rip 公开频道名称/编号作为浏览目录；有合适公开候选源的频道展示播放线路，付费或缺少 URL 的频道展示“待绑定”，其他地区/类别作为用户按需获取的选择。这样不会因为用户访问首页就批量请求第三方资源或将不需要的频道保存到本地。

## 隐私与依赖

- 浏览器从 iptv-org 域名直接拉取公开 M3U，必须允许 CORS。
- GitHub Pages 服务不可用或网络阻断时，已有频道和本地文件导入仍正常。
- 不向后台提交任何私人订阅链接、播放器认证信息或历史观看记录。
- 导入前会显示频道数量、跳过数、重复数，点击确认才写入 IndexedDB。
- 若发现权利状态不清晰的频道，请不要公开再传播其内容。
